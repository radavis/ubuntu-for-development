# ubuntu-for-development

My handbook for building web applications with Ubuntu as my OS.

[[radavis.github.io/ubuntu-for-development](https://radavis.github.io/ubuntu-for-development)]

## tools

- [honkit](https://github.com/honkit/honkit#readme) - a fork of gitbook

## usage

```bash
$ git clone git@github.com:radavis/ubuntu-for-development.git
$ cd ubuntu-for-development
$ npm i
$ npm start
$ open localhost:4000
```
