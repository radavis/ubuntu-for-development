## tldr

View a short description of bash commands with examples.

### Install

Install the tealdeer bash client.

```bash
$ sudo apt install tealdeer # or echo "tealdeer" >> ~/Aptfile && apti
```

### Usage

```bash
$ tldr --update
$ tldr --help
$ tldr tar
$ tldr apt
```
